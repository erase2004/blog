# 06: 圖片搬遷與舊圖片網址轉址

**What to build:** 把文章用到的圖片搬進統一圖片目錄，交給 Astro 最佳化。所有舊的圖片網址與附件頁都 301 到新的圖片網址，讓外站引用和 Google 圖片搜尋不會斷。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 只搬被內容、相簿或 SEO 設定引用的圖片，共 767 張
- [ ] 不搬：94 張孤兒圖、`-WxH` 縮圖、LiteSpeed 產生的 webp 與 `.bk` 備份、超過 2560px 的相機原圖
- [ ] 圖片依文章 slug 分子資料夾放進統一圖片目錄；網站共用圖放在共用子資料夾；檔名去掉 `-scaled`
- [ ] 內容裡的圖片引用改指向新檔案，包括 `i0.wp.com` 的 Photon 網址和縮圖網址
- [ ] 圖片由 Astro 輸出 webp 與響應式尺寸；在手機寬度下，瀏覽器下載的是對應尺寸的 webp，而不是原圖
- [ ] 舊網址對應表加入兩類對應：舊 upload 路徑（含帶 `-scaled` 的檔名）→ 新圖片；附件頁網址 → 新圖片
- [ ] 孤兒圖的附件頁不轉址，直接回 404
- [ ] 建置時產生 `_redirects`，把舊 upload 路徑與附件頁 301 到 Astro 實際輸出的圖片網址
- [ ] `_redirects` 的靜態規則總數超過 2,000 條時，建置直接失敗
- [ ] 網址檢查：sitemap 快照裡的 772 筆圖片網址與附件頁轉址都通過，並從待完成清單移除
- [ ] 更新搬遷日誌
