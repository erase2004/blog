# 22: 回到頂部按鈕

**What to build:** 讀者在長文章或列表往下捲之後，可以點畫面右下角的按鈕快速回到頁面頂端。這是站長核可 15 號版型時追加的需求。

**Blocked by:** 15

**Status:** resolved

- [x] 所有頁面的右下角都有「回到頂部」按鈕，放在共用版型裡
- [x] 往下捲超過約一個畫面高度才出現，在頁面頂端時隱藏
- [x] 點擊後平滑捲回頂部；系統設定 `prefers-reduced-motion: reduce` 時改為直接跳回
- [x] 回到頂部後，鍵盤焦點移到頁面開頭，可以繼續用 Tab 操作
- [x] 是真正的 `<button>`，有「回到頂部」的無障礙名稱，可以用鍵盤操作，有清楚的 focus 樣式
- [x] 樣式沿用 15 號的配色（深色底 `#1a1a1a`、白色箭頭），對比符合 WCAG AA
- [x] 手機寬度下不遮住內容、頁尾連結或留言區，也不造成水平捲動（15 號的 320px 檢查要通過）
- [x] 不依賴前端框架；JS 很小，沒有 JS 時按鈕不顯示
- [x] 更新搬遷日誌
